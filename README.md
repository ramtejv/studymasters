# Studymasters

AI-powered study platform that turns a student's study material into personalized quizzes and adaptive practice.

## Problem

Students often have plenty of study material but lack an efficient way to test their understanding and identify weak topics.

## Planned Solution

StudyMasters will:

1. Accept study material from students
2. Extract and understand the content using AI
3. Identify important topics
4. Generate MCQs based on the material
5. Analyze quiz performance
6. Identify weak topics
7. Generate targeted practice questions

## Planned Tech Stack

- React
- Vite
- Tailwind CSS
- Python
- FastAPI
- LLM API
- PostgreSQL / Supabase
